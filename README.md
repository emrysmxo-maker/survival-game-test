# Survival: Тест-Полигон

Тестовый полигон, работающий на настоящем движке игры Survival Game с 3D-постройками и динамическими тенями солнца.

## Особенности:
1. Полный движок оригинальной игры: 2K текстуры почвы, настоящие деревья Poly Haven, 3D Soldier.glb и 3D Zombie.glb.
2. 4 реалистичные постройки выживания:
   - 🏕️ Охотничья бревенчатая изба (сруб)
   - 🎖️ Военный блокпост с наблюдательной вышкой и мешками с песком
   - 🏚️ Заброшенный дом с обрушенной крышей
   - 🚪 Укреплённый бункер выживших со стальной гермодверью
3. Честные динамические тени от солнца (без статичных чёрных овалов под зданиями).
4. Переключатель качества в реальном времени (`⚡ УЛЬТРА 3.3x` -> `ВЫСОКОЕ 2.0x` -> `СРЕДНЕЕ 1.5x` -> `ЭКОНОМ 1.0x`).
5. Уникальный PWA-манифест для отдельной установки WebAPK рядом с основной игрой.
