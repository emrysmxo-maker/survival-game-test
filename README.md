# Survival Game — Тест-полигон (3D Модели и Постройки)

Изолированный тестовый полигон для проверки 3D-моделей построек, динамических теней солнца и графики без изменения кода основной игры.

## Возможности тестового полигона:
1. **Реалистичные 3D-постройки для стиля игры:**
   - 🏕️ **Охотничья бревенчатая изба (Сруб)**: срубленные брёвна, крыльцо с перилами, черепичная крыша, каменная печь с дымоходом, окна и приоткрытая дверь.
   - 🎖️ **Военный блокпост**: наблюдательная вышка высотой 6.5м с лестницей и настилом, U-образный бруствер из мешков с песком, армейские бочки ГСМ, ящики снабжения и маскировочный тент.
   - 🏚️ **Заброшенный дом**: полуразрушенные кирпичные стены, обрушенные стропила, уцелевший скат крыши и завалы битого кирпича.
   - 🚪 **Укреплённый бункер выживших**: железобетонный портал, герметичная стальная дверь со штурвалом, вентиляционный грибок, радиомачта и мешки с песком.
2. **Динамические тени солнца (без статичных чёрных пятен):**
   - Никаких искусственных овалов под зданиями — все тени честно рассчитываются источником света (солнцем).
   - Кнопки времени суток: **☀️ День**, **🌅 Закат**, **🌙 Ночь**, **⏰ Авто (15-мин цикл)**. При изменении времени тени плавно удлиняются, поворачиваются и меняют мягкость.
3. **Регулировка качества (чтобы тест не тормозил):**
   - Кнопка **⚡ КАЧЕСТВО**:
     - **Ультра (3.3x)**: нативное ультра-разрешение RedMagic 10 Pro, 2048px тени, максимальная чёткость.
     - **Высокое (2.0x)**: 1024px тени, баланс графики и энергопотребления.
     - **Среднее (1.5x)**: 512px тени, высокая производительность.
     - **Эконом (1.0x)**: тени отключены, максимальный FPS на любых устройствах.
4. **Управление RedMagic 10 Pro (две руки):**
   - Левая половина экрана — джойстик ходьбы.
   - Правая половина экрана — плавающий джойстик огня и прицеливания (стреляет сразу туда, куда направлен палец).
   - Кнопка **АВТО ОГОНЬ** и кнопка **ЗОМБИ +** (с правильным ростом ~1.8м).
5. **Установка второго отдельного АПК:**
   - Страница настроена как независимое PWA (`Survival Тест`).
   - Нажатие «Добавить на главный экран» в Chrome устанавливает отдельный второй значок/приложение рядом с основной игрой.
