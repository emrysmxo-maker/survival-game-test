# Полигон 3D: Модели и Укрытия (Survival Game)

Изолированный тестовый полигон для проверки 3D-моделей построек, динамических теней солнца и графики без изменения кода основной игры.

## Возможности:
1. **Реалистичные 3D-модели укрытий для стиля выживания:**
   - 🏕️ **Охотничья бревенчатая изба (Сруб)**: срубленные брёвна, крыльцо с навесом и перилами, черепичная крыша, каменная труба и дверь.
   - 🎖️ **Военный блокпост**: наблюдательная вышка 6.5м с настилом и лестницей, брустверы из мешков с песком, армейские бочки и ящики.
   - 🏚️ **Заброшенный дом**: полуразрушенные кирпичные стены, обрушенные стропильные балки и завалы битого кирпича.
   - 🚪 **Бункер выживших**: железобетонный портал, гермодверь со штурвалом, вентиляционный грибок и радиомачта.
2. **Честные динамические тени от солнца:**
   - Никаких искусственных чёрных овалов под зданиями — тени рассчитываются источником света (солнцем) и плавно падают на почву.
   - Кнопки времени суток: **☀️ День**, **🌅 Закат**, **🌙 Ночь**, **⏰ Авто**.
3. **Регулировка качества (кнопка ⚡ КАЧЕСТВО):**
   - **Ультра (3.3x)**: нативное разрешение для RedMagic 10 Pro, 2048px тени.
   - **Высокое (2.0x)**: 1024px тени.
   - **Среднее (1.5x)**: 512px тени.
   - **Эконом (1.0x)**: тени отключены для максимального FPS.
4. **Управление RedMagic 10 Pro (две руки):**
   - Левый стик — ходьба.
   - Правый стик — прицел и огонь.
   - Кнопка **ЗОМБИ +** (с правильным ростом ~1.8м).
   - Кнопки быстрого перемещения: `[🏕️ Сруб]`, `[🎖️ Блокпост]`, `[🏚️ Руины]`, `[🚪 Бункер]`.
5. **Отдельная установка (WebAPK):**
   - Название приложения: **«Полигон 3D: Модели»** (ярлык: **«Полигон 3D»**).
   - Уникальный идентификатор и значок для раздельной установки рядом с основной игрой.
